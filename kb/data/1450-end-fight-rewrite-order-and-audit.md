## Reading

The interesting part is not the rewrite — it's the sequence. Dan read a
"complete" rewrite, and his first substantive response was not praise or
correction of a detail but a scope failure: the article's actual subject
(the group chat) wasn't in it. The draft had mistaken the 1:1 thread for
the whole event because that was the source handed to it. Then the second
order: don't just summarize the sources — judge the people. "Make character
judgements" is Dan explicitly demanding the interpretive layer the wiki
usually hedges.

Pattern candidate (needs a third instance): **completeness-audit of
'finished' work** — Dan holds the full source set in memory and checks
deliverables against it rather than against their stated scope. Instance 1:
this catch. Instance 2 (same morning): ordering the rewrite at all because
the old page was stale. Watch for the next one before naming it a pattern.
