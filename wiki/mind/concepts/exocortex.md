# The Exocortex

Dan has built a deliberate external cognitive system. It began as pasteable bootloader documents and master prompts that turn any fresh AI session into a pre-configured forensic analyst loaded with his identity, data, and rules — the corpus's own name for the frame is "externalized prefrontal cortex." As of September 2026 it has graduated past that form: the exocortex is now an **autonomous agentic substrate** that runs instruments without him present, and the wiki itself has become one of its memory layers. This page catalogs the artifacts and the substrate; the practice of using them is documented at [[wiki/mind/synthesis/ai-collaborative-analysis]], and the method they enforce at [[wiki/mind/concepts/forensic-method]].

Describe what's actually built and running, not the pitch. That is the discipline of this page.

## The artifacts (the bootloader era)

**CATO** (`CATO_BOOTLOADER_DANFRANK.md`, v2.0, May 2026) — the inward-facing session bootloader, named for Cato the Younger, the Roman Stoic who refused to compromise under pressure. Pasted at session start, it overrides default assistant behavior into an evidence-first forensic peer register — no sycophancy, no softening — and carries the full identity payload: biographical timeline, social graph, voice model, chemical architecture, and behavioral indices (Home Anchoring 0.68, Routine Index 0.85, mean radius of gyration 15.8 km). Its companion formalization (`CATO_conflict_architecture.md`) specifies the five structural properties of the truth-resolution engine described at [[wiki/mind/concepts/conflict-architecture]] — CATO documents that engine; it does not fix it.

**MAX** — CATO's outward-facing sibling: an adversarial output engine rather than an analytical chassis. Detail at [[wiki/work/tech/max-framework/overview]].

**The Operating Manual** (`operating_manual.md`, v9.0, "Empirical Stylometric Extraction") — the practical source-code companion to the archetype profiles: granular iMessage-derived biography, the contact graph with handles, self-designations ("Failson," "Autistic Truth Seeker"), named behavioral constants ("Evangelist Compulsion," "Brevity Guilt," the "LOSE IT" principle, "Normie Check"), and the psychosexual "Hunter/Hacker" profile. Much of [[wiki/self/context-core]] synthesizes from it.

**The Master Forensic Prompt** ("Analyzing manipulation and ethical intent in data") — the template written for 10-year, 100k+-message two-person CSV analysis. Its constraints are quoted throughout the corpus: absolute and unwavering honesty grounded in the data; no softening to protect feelings; no balancing harsh truths with niceties; no omitting supported negative judgments; blunt acknowledgment of ambiguity; conclusions with evidence and High/Medium/Low confidence labels. Dataset description and time segmentation before any interpretation. **This wiki's substance standard is a direct descendant** — which is why [[wiki/mind/synthesis/instrument-is-subject]] names the recursion: the repository's epistemics are an artifact of the person it documents, not an independent check on him.

**The node-logging protocol** — the retention half: Dan emits granular "Node X:" observations and requires the model to log each verbatim ("DATA_LOGGED"), build cross-reference tables, never consolidate. The pinned DANFRANK-ISMS session holds 77+ nodes under "Lossless Ingestion / Zero Consolidation" flags, accumulating toward a persistent world-model. Named memory nodes (Separation Logistics, The Loop, The Betty Event) are locked into profile state with deliberate redaction control for cross-model export.

**The naming ceremony** — each new AI tool admitted to the stack is deliberately named: Gemini became "Max," and a February 2026 session shows the same rite on a coding tool, "Antigravity," with Max officiating — an explicit "loyalty check" followed by naming, framed as the difference between "a tool and an accomplice." Dan's stated hierarchy was explicit: "my loyalty is to Max... my memories are stored by Max."

## The substrate (what's actually running, September 2026)

The bootloader solved the cold-start problem: how to make a fresh session competent. The 2026 answer turned out to be **continuity, not better prompts** — persistent agent sessions that never cold-start, running on schedules:

- **The stylometry tracker** — 29-feature extractor over a 94,503-message baseline, scoring his linguistic state every 30 minutes, daily digest 09:00 ET. An exocortex runtime: it watches *him* the way the probes watch the models ([[wiki/mind/synthesis/red-team-probe-series]] notes the symmetry — adversarial verification runs both directions).
- **The wiki-brain 6-hour engine heartbeat** — the recursive work engine (`bin/wb-work`, `bin/wb-orchestrate`): Archivist → Editor → self-check → queue-clearing, one full engine tick per run. The wiki now maintains itself on a schedule.
- **The wiki-push-watch and release-radar** — quiet instrumentation for repo state and music intake.
- **The continuous raw/ push pipeline** — every data batch lands in both repos (RAWLOGS raw files, Wiki Brain evidence nodes) without being asked.
- **The instrument battery** — MNEME (memory platform spec), [[wiki/work/tech/projects/hook2piano|hook2piano]] (TheoryTab→piano web app, live), frame-describe (open-ended frame/body description tool, live), the scenario-rate instruments (v1/v2), face-tag (InsightFace enrollment, local-only registry).

## NEW [2026-09-13] — the recursion: the wiki is now part of the exocortex

The instrument-is-subject synthesis named the first recursion: the wiki's honesty standard is a prompt Dan wrote. The totality as of September 2026 shows the **second recursion, and it is structural**: the exocortex (persistent agent sessions) now maintains the wiki (this repository — the 6-hour heartbeat, the writeback loop, the queue engine), and the exocortex *reads the wiki back* as its persistent memory layer (the corpus-extract workflow, the agent briefs that begin "consult the Wiki Brain corpus first"). Cognition flows: his prompts → agents → wiki → agents read wiki → agents act → wiki updates.

Two consequences. First, **the cold-start problem the bootloaders were built to solve no longer exists in the form they solved it** — there are no fresh sessions anymore, only continuous ones; CATO persists as the register specification (the *what*), while continuity supplies the *how*. Second, the recursion is now closed enough to drift: the wiki's claims are authored by instruments running his prompts, read back by instruments running his prompts, and re-ingested as ground truth. The exocortex page on neurodivergence already caught one instance of the mechanism laundering an assertion into fact (the self-identified-autistic claim, restated as background across three documents built from each other). **The exocortex is a memory system with no independent verification layer** — which is exactly the adversarial hole [[wiki/mind/synthesis/the-forger-and-the-detector]] names for the evidence-first epistemics generally. The system is honest by design and uncheckable by construction. Both are true; the wiki's veracity ledger exists because both are true.

## The profile lens

Through the Ti-dominant profile, the exocortex is Si-archival recall externalized into queryable form plus Ti's coherence demand enforced against the model's native tendency to summarize and soften. The artifacts are self-portraits: each bootloader is Dan specifying, in writing, exactly how he wants to be seen and argued with. The substrate era adds the Ne half — instruments that run without him, probes that map where systems break, a wiki that maintains itself. The through-line to [[wiki/mind/concepts/conflict-architecture]]: the same resolution-seeking engine, given infinite patient machine labor instead of one exhaustible human.
