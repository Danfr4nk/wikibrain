# The Zero-Initiation Default

**Idea Journal — 2026-10-18, pass C (action initiation under ambiguity).**

## Profile prior (Stage 1)

- **Row 5 (weight 9, verdict: supported, A+B convergent).** Explicit-over-inferred meaning: stated text registers, ambient/implied signal does not. The row's own Predicts column states the thesis's lineage verbatim: *"Rule-changes require explicit statements; ambiguity stalls rather than improvises."* This entry is a test of that prediction against five dated episodes. Load-bearing.
- **Row 6 (weight 9, verdict: supported, Layer A).** Rules install and revoke only via explicit statements (no-counter-rule architecture). The mechanism behind the default: with nothing installed, there is no rule under which action can run. Load-bearing.
- **Row 1 (weight 8.5, verdict: supported).** Verdicts are categorical/binary; no graded middle. The initiation gate is therefore on/off, not graded: there is no "provisional" middle register in which half-authorized action lives. Load-bearing for the gate shape.
- **Row 23 (weight 7, verdict: leans→supported).** Reassurance decays; the check-in loop is the observable surface. The permitted substitute move under ambiguity: statement-request turns (re-asks) that solicit the missing explicit statement without changing any state. Load-bearing for the substitute.
- **Row 27 (weight 8, verdict: leans yes).** Sociability 3: initiating contact/plans at 0.73× baseline. Initiation exists without explicit rules in social contact — this row killed the unscoped thesis (see Genesis) and bounds the scoped one: the zero-initiation default applies to mandate-governed episodes, not to all behavior. Load-bearing as the scope bound.

No silent, inverted, or ≤4 row is load-bearing. Row 30 (Impulsiveness 96, silent, weight 3) is not touched: nothing here claims anything about interior regulation.

## Theory (Stage 2 — profile-vocabulary statement)

In mandate-governed episodes — where a standing mandate, delegation framework, or rule-set exists and the question is what action is authorized — **when no explicit statement installs the action (which act, by whom, changing which state), outbound initiation in that episode is zero.** The only output emitted is statement-request turns (row-23 check-in rungs) soliciting the missing explicit statement; no state changes, no workarounds, no provisional self-authorized action. The gate is binary (row 1): the substitute for action is not a graded half-action but a different turn type entirely — a request for the install.

Stated in observables only: initiation = the count of novel action-initiating turns in a dated episode; mandate-ambiguity = episodes where the dated record shows a live goal or pending question and no explicit statement installing the action; statement-requests = turns whose content is an explicit request for a stated rule ("just say the word"-form), with zero measured state drift after them. "Stall" is an observable (zero initiation), not an interior state — no claim is made about felt uncertainty. "Suspends" is what the record shows: output does not initiate.
