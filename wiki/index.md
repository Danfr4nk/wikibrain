# Idea Journal

Commissioned 2026-10-03. Four new theories a day about how Dan's brain
operates — each one built from a cluster of wiki information read together,
each one generated in an isolated pass so the entries do not contaminate
each other, and each one required to survive the profile before it is
allowed to stand. The journal's raw material is the whole corpus; its
referee is the weighted cognitive-personality profile
([[wiki/mind/profile/index|the profile cluster]], as priced by the
weighted profile instrument in the wiki-brain-improvement goal workspace).

## The protocol (in brief)

Every entry is generated under the profile-first protocol, in five stages:

1. **Profile prior.** Before drafting, the weighted profile claims the
   theory touches are listed with their weights. A thesis that needs a
   claim the corpus audit found silent, inverted, or weight ≤ 4 stops here.
2. **Profile-vocabulary statement.** The thesis is restated using only
   supported profile vocabulary. Interior-state language ("needs,"
   "drives," "feels") must be translated to attention-level observables —
   what the record can actually show — or struck. The attention–interior
   boundary is binding: the held instruments see attention, not interior
   regulation.
3. **Adversarial rival check.** The profile's own rival hypothesis for the
   theory's shape is written down, with the discriminating observation
   that separates them, *before* confirmatory evidence is gathered.
4. **Layer-A evidence gate.** Every load-bearing claim needs at least one
   measured, primary-record leg. Dossier testimony can suggest; it never
   carries.
5. **Confidence gate.** Below a high-confidence match with the profile
   data, the process **restarts with a new thesis**. Patching is
   prohibited. Dead theses are preserved in the entry's Genesis section —
   being wrong on the record is data.

Each entry carries its stage record: Profile prior / Theory / Evidence /
Rivals & discriminators / Confidence & gate / Falsifier. An entry that
cannot show its stages has not been cross-checked.
