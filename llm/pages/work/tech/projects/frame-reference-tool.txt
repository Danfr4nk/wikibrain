# Frame Reference Tool

Commissioned 2026-09-15 during the intimate-clip frame analysis session (the
"eyes never open" dispute) — delivered at 04:12:42–43Z, the same night it was
ordered. Dan had commissioned it because frame disputes kept stalling on
descriptions of blur: "what I'm pointing at" vs "what you're looking at."

What it does, in his own workflow order:

1. Load the clip.
2. Set the frame rate — 29.83 for the mp4, 60 for the .mov (the two formats
   the forensics work was running on).
3. Step or jump to the exact frame.
4. Click the spot.
5. Hit **Copy Reference** and paste it back into chat.

Then Sammy pulls that exact frame and looks exactly where he points. No
arguing about blur — the reference is the address, not a description of the
thing at the address.

It is the read-path companion to Frame Describe (the write-path vocabulary
in [[wiki/work/tech/image-lab]]): Frame Describe says *how* to describe a
frame; the Frame Reference Tool says *which pixel of which frame* is under
discussion.
